# 🌍 Travel Explorer

A modern, feature-rich travel application that allows users to browse and explore events, locations, and transportation options around the world.

## ✨ Features

### 🎉 Events
- Browse various events including music festivals, food expos, art galleries, tech summits, and more
- Filter events by category (Music, Food, Art, Technology, Sports, Culture)
- Search events by name or location
- View event details including date, time, location, price, and description

### 🌍 Locations
- Explore amazing destinations worldwide
- Filter locations by type (Landmarks, Natural Wonders, Historical Sites, Islands, Urban)
- Sort by name or rating
- View detailed information including attractions, ratings, and descriptions
- Discover top attractions at each location

### 🚀 Transportation
- Browse multiple transportation options (Flights, Trains, Buses, Ferries, Car Rentals)
- Filter by transportation type
- Sort by price or duration
- View detailed route information, carriers, and schedules
- Compare different transportation options

## 🚀 Getting Started

### Prerequisites
- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser and navigate to `http://localhost:3000`

### Build for Production

To create a production build:
```bash
npm run build
```

To preview the production build:
```bash
npm run preview
```
